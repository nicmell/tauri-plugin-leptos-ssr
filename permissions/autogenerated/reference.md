## Default Permission

Lets the plugin's pages send requests with a body over IPC, read streamed responses, and open websockets

#### This default permission set includes the following:

- `allow-fetch`
- `allow-fetch-read-body`
- `allow-fetch-cancel-body`
- `allow-ws-open`
- `allow-ws-read`
- `allow-ws-send`
- `allow-ws-close`
